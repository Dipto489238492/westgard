WESTGARD RULES

WARNING RULE

Rule 1-2s

  • Definition: One point exceeds ±2SD[cite: 8].
  • Status: Warning only[cite: 8].
  • Action: Hold patient results[cite: 8].
  • Check: Inspect other control levels[cite: 8].
  • Outcome: Accept run if others pass[cite: 8].
STRICT REJECTION

Rule 1-3s

  • Definition: One point exceeds ±3SD[cite: 8].
  • Type: Random Error[cite: 8].
  • RCA: Air bubble or voltage spike[cite: 8].
  • CAPA: Re-mix and re-run identical control[cite: 8].
STRICT REJECTION

Rule 2-2s

  • Definition: Two consecutive points exceed same 2SD[cite: 8].
  • Type: Systematic Error[cite: 8].
  • RCA: Reagent decay or calibration drift[cite: 8].
  • CAPA: Recalibrate instrument immediately[cite: 8].
STRICT REJECTION

Rule R-4s

  • Definition: 4SD spread between two controls[cite: 8].
  • Type: Random Error[cite: 8].
  • RCA: Pipetting error or severe instability[cite: 8].
  • CAPA: Verify fluidics and QC lot placement[cite: 8].
MAINTENANCE TRIGGER

Rules 4-1s & 10x

  • Definition: Prolonged shift on one side[cite: 8].
  • Type: Systematic Error[cite: 8].
  • RCA: Lamp aging or reagent degradation[cite: 8].
  • CAPA: Schedule preventive maintenance[cite: 8].
