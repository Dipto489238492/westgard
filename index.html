NABL QC Multi-Rules (ISO 15189)

WARNING RULE

Rule 1-2s

  • Definition: One point exceeds ±2SD.
  • Status: Warning only.
  • Action: Hold patient results.
  • Check: Inspect other control levels.
  • Outcome: Accept run if others pass.
STRICT REJECTION

Rule 1-3s

  • Definition: One point exceeds ±3SD.
  • Type: Random Error.
  • RCA: Air bubble or voltage spike.
  • CAPA: Re-mix and re-run identical control.
STRICT REJECTION

Rule 2-2s

  • Definition: Two consecutive points exceed same 2SD.
  • Type: Systematic Error.
  • RCA: Reagent decay or calibration drift.
  • CAPA: Recalibrate instrument immediately.
STRICT REJECTION

Rule R-4s

  • Definition: 4SD spread between two controls.
  • Type: Random Error.
  • RCA: Pipetting error or severe instability.
  • CAPA: Verify fluidics and QC lot placement.
MAINTENANCE TRIGGER

Rules 4-1s & 10x

  • Definition: Prolonged shift on one side.
  • Type: Systematic Error.
  • RCA: Lamp aging or reagent degradation.
  • CAPA: Schedule preventive maintenance.
